# Offline Vosk Speech Model Directory

This directory stores the free, offline Vosk speech recognition model.

### Recommended Model:
- **Name**: `vosk-model-small-en-us-0.15`
- **Size**: ~40 MB
- **License**: Apache 2.0 (Free & Open Source)
- **Cost**: Strictly ₹0
- **Purpose**: Fast, low-latency offline speech recognition and keyword spotting.

When you approve Stage 2, LOVIX can download and extract this lightweight model here automatically, or you can place it manually.
